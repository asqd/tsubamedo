Что умеет

Коллекции — файлы в git

Один запрос — один TOML-файл. Приложение меняет только строки, которые вы правили, так что в диффе видна ровно ваша правка. Секреты — в *.local.toml, которые в git не попадают.

Большие ответы

Тело больше 8 МБ сразу уходит во временный файл: ответ на 263 МБ скачивается за 0,24 с и занимает 30 МБ памяти. Поиск, сворачивание, фильтр JSONPath — по всему ответу.

Цепочки и проверки

[capture] token = '$.token' — и другие запросы пишут просто {{token}}; вход отправится сам, когда токена нет. Проверки строками: status == 200, $.items count > 0, JSON Schema.

Скрипты Postman и Insomnia

JavaScript до и после запроса. pm.test, pm.expect, pm.environment, CryptoJS работают как есть — переезд не ломает тесты.

Импорт

Insomnia (v4 и v5), коллекции и окружения Postman, OpenAPI 3 и Swagger 2 со схемами ответов, HAR из браузера, команда curl, вставленная в адрес.

Авторизация и сеть

OAuth 2.0 (вход в браузере с PKCE, client credentials, обновление токена), Digest, cookie по окружениям, системный прокси и SOCKS5, клиентские сертификаты PEM и .p12.

Сравнение stage и prod

Тот же запрос в другом окружении или прошлый ответ из истории: JSON по смыслу, с путём каждого изменения; изменчивые заголовки и поля можно не сравнивать.

Установка

TsubameDo не подписан сертификатом Apple и Microsoft: это стоит денег, а программа бесплатная и раздаётся напрямую. Поэтому система при первом запуске переспросит. Ниже — как ответить ей один раз.

macOS

  1. Откройте DMG и перетащите TsubameDo в «Программы».
  2. Запустите. macOS скажет, что не может проверить приложение, — нажмите «Готово».
  3. Откройте «Системные настройки» → «Конфиденциальность и безопасность», внизу нажмите «Всё равно открыть» и введите пароль.

На macOS 12–14 проще: щёлкните TsubameDo в «Программах» правой кнопкой → «Открыть» → «Открыть».

Или одной командой в Терминале: xattr -dr com.apple.quarantine /Applications/TsubameDo.app

Windows

  1. Запустите установщик.
  2. SmartScreen скажет «Система Windows защитила ваш компьютер» — нажмите «Подробнее», потом «Выполнить в любом случае».

WebView2, на котором работает окно, в Windows 10 и 11 уже есть; если нет, установщик его поставит.

Linux

  1. AppImage: chmod +x TsubameDo-*.AppImage и запустите.
  2. Или пакет: sudo apt install ./tsubamedo_*.deb

Нужен WebKitGTK 4.1: Ubuntu 22.04, Debian 12, Fedora 38 и новее.

Проверить, что файл тот самый

Сравните сумму с файлом .sha256 со страницы выпуска: shasum -a 256 ~/Downloads/TsubameDo-*.dmg (macOS и Linux — sha256sum, Windows — Get-FileHash).

CLI для терминала и CI

Те же коллекции из командной строки: проверки, цепочки, отчёт JUnit для GitLab, Jenkins и GitHub Actions. Скачанный через curl файл macOS не помечает, спрашивать ничего не придётся.

# macOS Apple Silicon; для Intel и Linux — имя архива со страницы выпуска
curl -L https://github.com/asqd/tsubamedo/releases/latest/download/tsubamedo-ВЕРСИЯ-macos-apple-silicon.tar.gz | tar xz
sudo mv tsubamedo /usr/local/bin/

tsubamedo run -e stage --junit report.xml       # вся коллекция, код выхода для CI
tsubamedo compare orders/list -e stage --with prod
tsubamedo code orders/create -l python-requests

Ваши данные остаются у вас

Ни аккаунта, ни облака, ни телеметрии. Коллекции лежат там, где вы их создали; история, cookie и токены — в папке данных приложения на этом компьютере. TsubameDo сам никуда не ходит: в сеть уходят только ваши запросы.
