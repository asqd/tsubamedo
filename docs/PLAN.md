# План TsubameDo

Рабочий план. После каждого шага отмечаем сделанное здесь.

## Зачем

Три вещи, которые мешают в Insomnia, — это главные требования, и каждый этап их проверяет:

1. **Тяжёлый.** Цель: холодный запуск приложения меньше 1 с, в покое не больше 150 МБ памяти
   вместе с WebView, DMG меньше 15 МБ.
2. **Не открывает большие ответы.** Цель: JSON на 300 МБ открывается без зависания —
   прокрутка, поиск, сворачивание дерева, фильтр по JSONPath.
3. **Требует аккаунт.** Никаких аккаунтов, облака и телеметрии. Коллекции — файлы в git.

Как в прошлых программах: ядро на Rust, оболочка на Tauri (как Musubiko), сначала macOS,
потом Windows и Linux через CI. Без аккаунта Apple Developer: сборка без подписи, раздача
с сайта, на странице загрузки — как открыть неподписанное приложение.

Чем отличаемся от похожих программ: Yaak (тоже Tauri и Rust), Bruno (тоже файлы в git),
Postman. У нас — точечное сохранение файлов без лишнего диффа, большие ответы как
сильная сторона, CLI из того же ядра для CI и сравнение ответов.

## Этап 0. Ядро и CLI — сделано

- [x] Отправка запроса со своим соединением: время DNS, подключения, TLS, ожидания и загрузки.
- [x] HTTP/1.1 и HTTP/2 (ALPN), TLS на rustls с системными сертификатами (видит корпоративные
      CA), отключение проверки для тестовых стендов.
- [x] Перенаправления как в браузере (303 и POST после 301/302 становятся GET, авторизация не
      уходит на другой сервер), лимит 10.
- [x] gzip, deflate, brotli; размер по сети и после распаковки.
- [x] Большие ответы: тело больше 8 МБ пишется во временный файл, который удаляется вместе
      с ответом. 263 МБ — 0,24 с и 30 МБ памяти.
- [x] Модель запроса: параметры, заголовки (выключенные остаются в файле), Basic, Bearer,
      API key, тело JSON, текст, form, multipart с файлами, файл целиком.
- [x] Файл запроса в TOML через `toml_edit`: сохранение без изменений ничего не переписывает,
      правка меняет только свою строку. YAML не подошёл: в Rust нет редактора YAML, который
      сохраняет оформление.
- [x] Коллекция: папка, окружения, секреты в `*.local.toml`, переменные с вложенными ссылками,
      встроенные `$uuid`, `$timestamp`, `$env.ИМЯ`; понятная ошибка со списком всех
      незаданных переменных.
- [x] CLI: `send`, `run`, `check`, `init`. Сообщения на русском.

## Этап 1. Приложение — минимальная версия

Замеры собранного приложения (TsubameDo.app 0.1, MacBook разработчика). Память — как в
колонке «Память» Мониторинга системы (`footprint`), по всем процессам приложения. Сумма RSS
больше, но она по разу считает в каждом процессе общие библиотеки WebKit, которые система
держит один раз.

| Что | Цель | Сейчас |
|---|---|---|
| Окно после запуска | < 1 с | 0,88 с |
| Память в покое, вместе с процессами WebView | ≤ 150 МБ | 111 МБ после запуска (приложение 22, WebContent 55, GPU 28, сеть 6); 128 МБ после закрытия вкладки с ответом на 263 МБ |
| Размер приложения | DMG < 15 МБ | 16,3 МБ без сжатия, DMG ещё не собирали |
| JSON 263 МБ: красивый вид | без зависания | 0,2 с на форматирование на 10 ядрах (было 1,4 с в одном потоке), затем 28 млн строк листаются сразу |
| Память с этим ответом | — | 264 МБ всего, приложение 167 (индекс строк 56 и свёртки 32) |
| Поиск по нему без учёта регистра | — | меньше секунды до первого совпадения, считает до 1 млн |

- [x] Каркас Tauri 2 в `apps/desktop` (React + TS + Vite, как Musubiko). Все команды окна
      живут в `core/tsubamedo-session` за одним вызовом `call`: и приложение, и мост для
      браузера (`make bridge`) пересылают в него, поэтому расходиться им не в чем.
- [x] Окно: коллекция слева, запрос посередине, ответ справа, разделитель тянется.
- [x] Редактор запроса: метод, адрес, параметры, заголовки, авторизация, тело (JSON, текст,
      форма, multipart, файл), настройки. Правки сразу сохраняются в файл через
      `RequestFile::update` — меняется только своя строка (проверено на живом файле).
- [x] Окружения: переключатель в верхней панели, выбор запоминается для коллекции.
- [x] Черновик без коллекции — как адресная строка, хранится только в окне.
- [x] Ответ: статус, время, размер (и сжатый по сети), заголовки, время по фазам полосками,
      что именно ушло на сервер.
- [x] **Просмотр больших ответов:**
  - [x] ядро держит текст (как есть или JSON с отступами во временном файле) и индекс строк по
        2 байта на строку; окно просит только видимые строки;
  - [x] своя прокрутка и полоса — браузер не прокручивает 28 млн строк;
  - [x] сворачивание объектов и массивов, «Свернуть» верхний уровень (до 100 000 объектов);
  - [x] поиск в ядре по всему виду, без учёта регистра и для кириллицы, переход по совпадениям;
  - [x] подсветка JSON только для видимых строк; «Копировать» до 20 МБ, «Сохранить…» любого размера.
- [x] Отмена запроса, ⌘↵ — отправить, ⌘O — открыть коллекцию, ⌘N — новый запрос, ⌘F — поиск в ответе.
- [x] Иконка: ласточка (`design/make-icon.swift`).
- [x] Память в покое: 111 МБ после запуска. Прежние 157 МБ были суммой RSS — в ней общие
      библиотеки WebKit посчитаны в каждом процессе. Ядро держит тело и виды ответа, пока
      его показывает хоть одна вкладка (`retain`): закрыли вкладку с ответом на 263 МБ —
      приложение вернулось со 176 до 36 МБ, свободное ядро отдаёт системе
      (`malloc_zone_pressure_relief`). Раньше держались последние 30 ответов.
- [x] Вкладки: несколько открытых запросов, у каждого свой ответ и своя отправка; черновиков
      сколько угодно. Вкладка, открытая из боковой панели и не тронутая (курсивом), уступает
      место следующей — просмотр списка не плодит вкладки. Открытые вкладки запоминаются для
      каждой коллекции. ⌘T, ⌘W, ⌘1…⌘9, ⌃Tab, ⌘⇧[ и ⌘⇧]; средняя кнопка мыши закрывает.
      Меню macOS своё, без «Закрыть окно», поэтому ⌘W закрывает вкладку (проверено в приложении).
- [x] CodeMirror 6 для адреса, значений параметров, заголовков, полей авторизации и тела:
      JSON с подсветкой, сворачиванием, парными скобками и поиском (⌘F).
- [x] `{{Переменные}}`: заданные подсвечены, незаданные — красным с волнистой линией и списком
      под адресом ещё до отправки (с учётом вложенных: `base` → `{{host}}`). При наведении —
      значение и откуда оно (секреты из `*.local.toml` скрыты). После `{{` — подсказки:
      переменные окружения и встроенные.
- [x] Импорт из curl: команда, вставленная в адрес, становится запросом — параметры,
      заголовки, Bearer и Basic во вкладку авторизации, JSON, форма, multipart, файл, `-G`,
      `-k`, `$'…'` из «Copy as cURL» браузеров. «Вернуть как было» — в подсказке после вставки.
- [x] «Скопировать как curl» с подставленными переменными; проверено настоящим curl.
- [x] История отправленных запросов: в папке данных приложения (`~/Library/Application
      Support/app.tsubamedo.TsubameDo`), а не в коллекции, чтобы не попасть в git. Запрос
      хранится как написан, с `{{переменными}}`; значения Authorization, Cookie и заголовков
      с key/token/secret в «Отправлено» скрыты. Тела ответов до 1 МБ хранятся как пришли (если
      сервер вернул токен в теле, он там будет). 500 записей на коллекцию, группы по дням,
      фильтр «только этот запрос», очистка. Запись открывается вкладкой-черновиком с ответом.
      Неотправленные (незаданная переменная) не пишутся, сетевые ошибки — пишутся.
- [x] Боковая панель — дерево папок, как на диске, включая пустые. Правый клик или «⋯»:
      переименовать (имя = имя файла, недопустимые символы заменяются), дублировать,
      переместить в…, удалить в Корзину с подтверждением; для папок — новый запрос и папка
      внутри. Перетаскивание запросов и папок. Двойной щелчок — переименовать, новые запрос
      и папка сразу ждут имя. Открытые вкладки и история переезжают вслед за файлами.
- [x] Форматирование больших JSON на всех ядрах: тело режется на части сразу после запятых
      вне строк, части форматируются параллельно в свои файлы, индекс строк и свёртки
      сшиваются. 263 МБ — 0,2 с вместо 1,4 с, результат совпадает с `jq .` байт в байт.
      Хода форматирования в окне не нужно. Вложенность глубже 1000 уровней показывается как
      есть: отступы в ней занимали бы больше, чем сам ответ.
- [ ] Индекс строк без 2 байт на строку (только каждая 1024-я, остальное — поиском `\n`):
      ответ на 263 МБ держал бы на 56 МБ меньше.
- [ ] Сравнение с Insomnia на том же ответе — для страницы продукта.
